# Prompt template

Each image prompt is one block. Fill the brackets from Orte_Final. Do not shorten.

```
Create an extraordinarily detailed photorealistic documentary photograph of [PLACE NAME], catalog [ID], in the Empire flecken Drosselau, year 2512 IC, Warhammer Fantasy.

DISTRICT: [paste the matching district row — ground, walls/roof, colour, forbidden].

OBJECT: [paste the full place paragraph from Orte_Final].

The whole building or object fits in the frame. Eye-level three-quarter view, 35mm. Overcast cool north-European daylight (dusk only if the place text demands it). Materials and wear at archaeological scale — chips, moss, soot, mud splash, uneven handmade surfaces. No empty monument plaza. Surroundings belong to this district only.

At the BOTTOM EDGE of the image a small plain catalog mark only: [ID or unnumbered name].

Ultra-photorealistic, physically based, fine texture, environmental storytelling, no illustration look.

Negative: modern objects, cars, wires, plastic, cartoon, anime, cathedral, marble palace, stained-glass shafts, readable words other than the catalog mark, watermark, cropped building, people dominating the frame, [district-forbidden list], [place-specific forbidden].
```

Place-specific forbiddens to add when relevant

- 18 — no word WARHAMMER, no tall steeple
- 6 — no cat statue, no hammer-cross
- Shallya — no halo, no hospice
- 56 — no door leaves, no pews, no Sunday bell
- 57 — no temple tower, shrine not obvious
- 64 — nails paler than the wood
